1. Confirm Play Console developer account can create/publish a NEW app
   (Policy status OK; do not use the suspended listing).

2. Confirm code identity (already set in mobile/app.json):
   - name MotiveFX
   - package com.motivefx.app

   - versionCode 1
   - EXPO_PUBLIC_IAP_ENABLED=false in mobile/eas.json

   eas build --platform android --profile production

   - Financial features declaration if asked
