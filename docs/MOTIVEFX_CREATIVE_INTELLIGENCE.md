# MotiveFX Creative Intelligence Engine

> **Status:** Adopted (2026-08-29). First production milestone shipped in Ops Creative Lab.  
> **Doctrine:** Don't advertise a prediction. Advertise the intelligence behind the decision.  
> **Public product:** [MotiveFX.ai](https://www.motivefxai.com)  
> **Related:** [MOTIVEFX_OPS_MASTER_PLAN.md](./MOTIVEFX_OPS_MASTER_PLAN.md)

## Permanent creative doctrine

| MyMotiveLife | MotiveFX |
| --- | --- |
| Starts with the customer's life | Starts with the trader's uncertainty |
| Lifestyle / aspiration hooks | Clarity when the market is noisy |
| One critic (attention) | **Two mandatory critics** — Creative + Financial Claims |

**Don't sell “AI trading.” Sell clarity when the market is noisy.**

Pipeline:

```text
Market/Product Truth → Trader Persona → Trading Problem → Hook Battle
→ Hook Score → Market Story → Creative Concept → Caption / Image / Video
→ Creative Critic → Financial Claims Critic → Variants → Approval → Publish
→ Performance → Learning
```

The Financial Claims Critic can **block publication** regardless of Hook Score.

## Dual critics (mandatory)

1. **Creative Critic** — Will this stop a trader scrolling? Tension? First frame? Distinct from generic AI-trading ads?
2. **Financial Claims Critic** — Can we actually say this? Real/demo/sim? Returns implied? Advice language? Risk disclosure?

## Hook families

Market confusion · Signal overload · Contrarian · Decision tension · Missed context · Confluence · Timing · Demonstration · Trader pain · Pattern interrupt · Evidence challenge · AI misconception

## Hook score dimensions

SCROLL STOP · TRADER RECOGNITION · MARKET TENSION · CURIOSITY · SPECIFICITY · CLARITY · PRODUCT CONNECTION · EVIDENCE ORIENTATION · CREDIBILITY · COMPLIANCE → MOTIVEFX HOOK SCORE

Severe deductions: guaranteed outcome / profit promise / unsupported win rate / unsupported backtest / misleading P&L (−100); “AI knows the future” (−50); fake urgency (−40); generic cliché (−20).

## Creative modes

| Mode | Behavior |
| --- | --- |
| **EVERGREEN** | Product/problem advertising only |
| **MARKET-AWARE** | Current themes without trade recommendations |
| **LIVE_MARKET** | Consumes approved Market Truth from MotiveFX — AI never invents market state |

Rule: **Market data establishes truth. Code calculates. AI explains. Creative Intelligence packages the story.**

## Caption structure

HOOK → TRADER RECOGNITION → MARKET TENSION → EVIDENCE → MOTIVEFX REVEAL → INSIGHT → CTA

## Visual concepts (preferred)

- Conflicting evidence → WAIT  
- Confluence → 1 INDICATOR ≠ A TRADE  
- Confidence board (only real/authorized or clearly DEMO/SIMULATED)

Avoid: dark candlestick + glowing AI brain (generic competitor look).

## First production milestone

Every MotiveFX campaign generates ≥10 competing hooks, scores finalists, builds caption + visual + first-3-seconds concept, passes both critics, and produces creative hypotheses before approval.
