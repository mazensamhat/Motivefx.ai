HOW TO FILE THIS GOOGLE PLAY SUPPORT TICKET
===========================================

1. Open TICKET_DESCRIPTION.txt in this folder.
2. Select all text (Ctrl+A), copy (Ctrl+C).
3. Paste it into the Google Play support ticket issue description.
4. Attach these files from THIS folder to the ticket:
   - AAB_DOWNLOAD.txt           (direct AAB download URL; ticket form cannot accept >21MB)
   - REMEDIATIONS.md            (full remediations write-up)
   - DATA_DELETION_URL.txt      (public deletion page URL)
5. Optional: put your own Play Console Policy status screenshot in this folder, then attach that too.

Do NOT attach the .aab binary — the form rejects files over 21MB. Attach AAB_DOWNLOAD.txt instead.
